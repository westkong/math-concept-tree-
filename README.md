# 🌳 수학 개념 트리 탐색기

> 수학 개념을 입력하면 선수개념을 트리 구조로 분석해주는 AI 학습 진단 도구

**🔗 Demo:** https://westkong.github.io/math-concept-tree/

---

## 📌 프로젝트 소개

수학 강사로 학생들을 가르치면서 느낀 점이 있습니다.  
학생이 미분을 못 푸는 건 미분이 어려워서가 아니라, **극한이나 함수 개념이 빠져 있기 때문**인 경우가 대부분이었습니다.  
어디가 막혀 있는지 시각적으로 보여주는 도구를 만들고 싶었습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎯 개념 분석 | 수학 개념 입력 → 선수개념 5가지 중요도순 출력 |
| 📚 학년 표시 | 각 선수개념이 몇 학년 과정인지 표시 |
| 🔍 하위 탐색 | 선수개념 카드 클릭 → 그 개념의 선수개념도 펼쳐짐 |
| ⚡ 예시 태그 | 미분, 로그, 적분, 극한 등 빠른 입력 지원 |

---

## 🛠 기술 스택

- **Frontend:** HTML, CSS, Vanilla JavaScript (단일 파일)
- **AI:** Anthropic Claude API (개념 분석 + JSON 구조화 응답)
- **배포:** GitHub Pages

---

## 🚀 사용 방법

1. [사이트](https://westkong.github.io/math-concept-tree/) 접속
2. Claude API 키 입력
3. 수학 개념 입력 또는 예시 태그 클릭
4. **탐색하기** 클릭 → 선수개념 트리 확인
5. 카드 클릭 → 하위 선수개념 펼쳐보기

---

## 💡 활용 예시

**입력:** 미분

**결과:**
```
🎯 미분
├── 1. 극한 (고2) — 미분의 정의 자체가 극한으로 표현됨
├── 2. 함수의 연속성 (고2) — 미분 가능하려면 연속이어야 함
├── 3. 함수의 그래프와 기울기 (고1) — 미분은 접선의 기울기
├── 4. 다항함수 (고1) — 가장 먼저 미분하는 대상
└── 5. 지수와 거듭제곱 (중3) — 미분 공식에 지수 연산 필수
```

각 항목 클릭 시 → 해당 개념의 선수개념도 추가 분석
