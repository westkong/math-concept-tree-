# 🌳 수학 개념 트리 탐색기

> 수학 개념을 입력하면 선수개념을 트리 구조로 시각화하고, 이해도를 진단하는 AI 학습 도구

**🔗 Demo:** https://westkong.github.io/math-concept-tree-/

---

## 📌 프로젝트 소개

수학 강사로 학생들을 가르치면서 느낀 점이 있습니다.  
학생이 미분을 못 푸는 건 미분이 어려워서가 아니라, **극한이나 함수 개념이 빠져 있기 때문**인 경우가 대부분이었습니다.  
어디가 막혀 있는지 시각적으로 보여주고, 직접 진단까지 할 수 있는 도구를 만들었습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎯 개념 분석 | 수학 개념 입력 → 선수개념 5가지 중요도순 분석 |
| 🌳 D3.js 트리 시각화 | 선수개념을 노드 + 연결선 그래프로 시각화 |
| 🔍 클릭 확장 | 노드 클릭 → 하위 선수개념 3가지 추가 분석 |
| 📖 개념 상세 설명 | 노드 클릭 시 정의 + 핵심 공식 + 예시 표시 |
| 📐 수식 렌더링 | MathJax로 LaTeX 공식 렌더링 |
| 🧪 이해도 진단 | 각 개념별 단답형 문제 → AI 채점 + 피드백 |
| ⚡ 캐시 시스템 | 이미 불러온 개념은 재호출 없이 즉시 표시 |

---

## 🛠 기술 스택

- **Frontend:** HTML, CSS, Vanilla JavaScript (단일 파일)
- **시각화:** D3.js (트리 레이아웃)
- **수식:** MathJax 3
- **AI:** Anthropic Claude API (개념 분석 + 채점)
- **배포:** GitHub Pages

---

## 🚀 사용 방법

1. [사이트](https://westkong.github.io/math-concept-tree-/) 접속
2. Claude API 키 입력
3. 수학 개념 입력 또는 예시 태그 클릭
4. **탐색하기** 클릭 → 트리 시각화 확인
5. 노드 클릭 → 개념 설명 + 공식 + 진단 문제 확인
6. 진단 문제에 답 입력 → AI 채점

---

## 💡 활용 예시

**입력:** 미분

```
🎯 미분
├── 1. 극한 (고2) → 클릭 시 개념 설명 + 공식 + 진단 문제
│   ├── 수렴
│   ├── 수열
│   └── 무한
├── 2. 함수의 연속성 (고2)
├── 3. 함수의 그래프와 기울기 (고1)
├── 4. 다항함수 (고1)
└── 5. 지수와 거듭제곱 (중3)
```

각 노드 클릭 시:
- 📖 개념 설명
- 📐 핵심 공식 (LaTeX 렌더링)
- ✏️ 풀이 예시
- 💡 주의 포인트
- 🧪 이해도 진단 문제 + AI 채점
